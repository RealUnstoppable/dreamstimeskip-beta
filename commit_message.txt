refactor: apply DRY sweep, update error logging, optimize state management

This PR addresses three main objectives:
1. **DRY Sweep**: Replaced duplicated manual cart subtotal calculation loops in checkout.js and checkout.js.new with the imported calculateCartSummary utility function.
2. **Error Handling**: Ensured standard logging conventions by prefixing all console.error calls with "Manager info:" in account.js and checkout-related files for better troubleshooting.
3. **State Management**: Optimized caching memoization checks in account.js by stringifying mapped identifiers instead of entire unextracted document objects to prevent overhead and unnecessary re-renders.
