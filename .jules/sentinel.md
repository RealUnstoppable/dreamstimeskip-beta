## 2024-05-18 - Path Traversal Vulnerability
**Vulnerability:** In `server.js`, user-controlled input (`req.path`) is used to construct a file path without sufficient sanitization, allowing path traversal attacks via URL-encoded characters (like `%2e%2e%2f` for `../`) and potentially null bytes.
**Learning:** `req.path` in Express does not automatically decode URL-encoded slashes (`%2f`). If the path is not explicitly decoded before normalization or validation, an attacker can bypass naive string-based filters (like `.replace(/^(\.\.[\/\\])+/, '')`). Using `path.normalize()` with string replacement is insufficient to prevent path traversal when URL encoding is used.
**Prevention:** Always decode the URI component, reject null bytes (`\0`), resolve to an absolute path using `path.resolve(__dirname, '.' + decodedPath)` (or equivalent), and explicitly enforce directory boundaries by checking that the resolved path starts with the allowed root directory (`if (!filePath.startsWith(__dirname + path.sep) && filePath !== __dirname) return res.status(403);`).
