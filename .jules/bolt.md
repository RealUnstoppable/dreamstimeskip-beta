## 2024-05-18 - Replacing O(N) array lookups with O(1) hash maps in massive static lists
**Learning:** In a codebase with massive statically generated arrays (like `librarySongs` which spans ~29k lines), using standard array methods like `.find()` and `.findIndex()` for every lookup creates a significant execution bottleneck and thread blocking due to O(N) iteration overhead. This is especially problematic for core UI features like song playback or queue progression.
**Action:** When working with large static datasets in JavaScript, proactively pre-compute and store indexing `Map` instances (`songMap` and `songIndexMap`) during script initialization. Expose wrapper functions like `getSongById(id)` to perform O(1) hash map lookups. Always ensure that index fallbacks gracefully return `-1` to maintain parity with `.findIndex()`.
