## 2025-02-12 - Replacing Array.find with Map for getSongById
**Learning:** When maintaining cached Maps to optimize O(N) array lookups (like replacing `Array.find()` with `Map.get()`) for collections that can dynamically mutate (like `librarySongs`), a static Map becomes stale. Instead of complex listeners, checking `librarySongs.length !== lastLibraryLength` and lazily rebuilding the map is an effective, simple way to maintain cache correctness in dynamic environments, while preserving O(1) read performance.
**Action:** When creating caching mechanisms for arrays, always trace where and how the array might be mutated (`push`, `splice`, `unshift`). Either synchronize the cache on every write or lazily invalidate it on length/reference changes before reading.
