## 2024-05-18 - Debounce Product Search in `js/shop.js`
**Learning:** `shop.js` has a `renderProducts(searchQuery)` function that filters the product array and redraws the entire grid using `innerHTML`. The `#product-search` input existed in `shop.html` but was not wired up with an event listener. Without debouncing, adding a naive `input` event listener would trigger a full DOM rebuild on every keystroke, causing severe layout thrashing and jank.
**Action:** Always wrap expensive UI updates (like full-grid re-renders or API calls) in a debounced function (e.g. `setTimeout` of ~300ms) when binding them to rapid input events like typing.
