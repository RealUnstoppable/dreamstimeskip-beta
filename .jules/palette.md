## 2024-11-20 - Dynamic Character Counters & Accessibility
**Learning:** Hardcoded static limits like "0 / 500" create a false sense of feedback, confusing users who expect the interface to react to their input. Additionally, open-ended text inputs missing dynamic visual counters and screen reader announcements (`aria-live="polite"`, `aria-describedby`) fail to provide necessary constraints, leading to frustration for both sighted and screen reader users when limits are unexpectedly hit.
**Action:** Always implement dynamic character counters for textareas with limits. Link them using `aria-describedby`, make them announce changes politely with `aria-live="polite"`, provide visual cues (e.g., color change) when approaching the limit, and ensure the state resets on form submission.
