Accessibility Statement

Organization: Unstoppable LLC Standard: WCAG 2.1 Level AA Last Updated: November 2026

1. Our Commitment to Accessibility

Unstoppable LLC is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards to guarantee full and equal access to our platforms, services, digital storefronts, and web experiences under Title III of the Americans with Disabilities Act (ADA) and the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

2. Conformance Status & Standards

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

The Unstoppable Ecosystem (including realunstoppable.store, the Unstoppable Hub, Merch Store, Cart, Checkout, Medixly Music Player, and Dreams TimeSkip portal) strives to conform with WCAG 2.1 Level AA.

Key technical measures implemented across our ecosystem include:

  • Native Semantic HTML: Proper landmark elements (<header>, <nav>, <main>, <footer>) and hierarchical heading structures (<h1> through <h6>) to allow screen reader navigation.
  • Full Keyboard Navigation: All interactive controls, menus, filters, dialogs, forms, and checkout steps are fully operable via keyboard (using Tab, Shift+Tab, Enter, Space, and Escape keys) with high-contrast visible focus indicators (:focus-visible).
  • Skip to Main Content: Direct skip links enable keyboard and screen reader users to bypass repetitive header navigation and jump immediately to primary content.
  • Text Alternatives (Alt Text): Descriptive alternative text for all informational and product imagery, with decorative visual elements safely hidden from assistive readers using aria-hidden="true" or empty alt tags.
  • Form Labels & Autocomplete: Explicit form controls paired with programmatic labels, input assistance, and WCAG 1.3.5 compliant autocomplete tags for streamlined and reliable checkout submissions.
  • Color Contrast & Text Legibility: Color ratios engineered to meet or exceed the minimum 4.5:1 contrast requirement for normal text and 3:1 for large typography and active interface components.
  • Screen Reader Accessibility: Aria labels, live regions (aria-live), and dialog state attributes (aria-expanded, aria-modal) optimized for Apple VoiceOver (macOS / iOS), NVDA, JAWS (Windows), and Google TalkBack (Android).

3. Assistive Technology Compatibility

Our website and web applications are designed to be compatible with modern user agents and assistive technologies:

  • Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge on macOS, Windows, iOS, and Android.
  • Screen readers: Apple VoiceOver (macOS, iOS), NVDA and JAWS (Windows), TalkBack (Android).
  • Native browser text resizing up to 200% without loss of content or functionality.

4. Continuous Evaluation & Auditing

We evaluate accessibility across our codebase through both automated tooling and continuous manual testing:

  • Automated WCAG rule audits via axe-core, Google Lighthouse, and Chrome DevTools accessibility trees.
  • Manual screen reader evaluation with Apple VoiceOver and NVDA.
  • Keyboard-only traversal testing for all e-commerce flows (browsing, cart manipulation, and checkout).
